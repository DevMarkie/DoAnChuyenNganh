🏛️ Kiến Trúc Chống Đua Tranh 2 Tầng (2-Tier Concurrency Architecture)

TẦNG 1: REDIS IN-MEMORY LUA SCRIPT (FAIL-FAST) RAM < 2ms

Tất cả 100 requests chạm vào Redis trước. Script Lua nguyên tử tryAcquireSlot() kiểm tra và trừ slot trong RAM. 40 sinh viên đầu tiên nhận được slot; 60 sinh viên còn lại bị từ chối ngay lập tức tại RAM, không sinh tải hay chiếm connection của Database.

TẦNG 2: HIKARICP POOL & ATOMIC CONDITIONAL UPDATE ACID DB

40 sinh viên vào DB được xếp hàng mượt mà trong HikariCP Pool (15 connections). Câu lệnh SQL nguyên tử: UPDATE course_sections SET current_students = current_students + 1 WHERE id = :id AND current_students < max_students loại bỏ hoàn toàn nguy cơ Race Condition và chặn đứng 100% tình trạng Over-selling.
